# Project Visual Assets

Place real project media in these project folders.

- `p1-city-scavenger/p1_city_scavenger_cover_v01.png`: homepage cover for the AI Film concept.
- `p1-city-scavenger/p1_city_scavenger_poster_v01.png`: modal poster for the AI Film concept.
- `p2-machine-vision-archive/p2_machine_vision_cover_v01.png`: homepage and modal cover for the machine vision archive.
- `p2-machine-vision-archive/p2_machine_vision_board_v01.png`: full concept board for the machine vision archive.
- `p3-shutter-drift/p3_shutter_drift_cover_v01.png`: homepage cover for SHUTTER DRIFT.
- `p3-shutter-drift/p3_shutter_drift_game_cover_v01.webp`: modal game interface cover for SHUTTER DRIFT.
- `p4-haptic-image-study/p4_haptic_image_cover_v01.png`: homepage and modal cover for Haptic Image Study.
- `p4-haptic-image-study/p4_haptic_image_board_v01.jpg`: full concept board for Haptic Image Study.
- `p3-gameplay-demo.mp4`: optional compressed gameplay demo for SHUTTER DRIFT.

Video files must be compressed before being added. The homepage should not load large videos directly; gameplay video is only loaded inside the project modal.

## Photo / Visual Requirements

### P1 — AI Film: City Scavenger

- Cover: communicate the AI film atmosphere and after-photography direction.
- Poster: act as the main concept poster inside the project modal.
- Next evidence needed: keyframes, selected stills and a 40–45s test sequence.

### P2 — Machine Vision Archive

- Cover: quickly show the machine vision archive concept.
- Board: explain the OpenCV detection, JSON archive and ESP32 feedback structure.
- Next evidence needed: hardware test photos and a screen recording of the JSON archive workflow.

### P3 — SHUTTER DRIFT

- Cover: introduce the project identity on the homepage.
- Game cover: show the first-person camera-game interface inside the modal.
- Next evidence needed: 3 gameplay screenshots and one 15–30s compressed gameplay recording.

### P4 — Haptic Image Study

- Cover: introduce the haptic black-box concept.
- Board: show GLCM texture mapping, vibration motors, RGB feedback and interaction logic.
- Next evidence needed: hardware parts photo and first single-module test recording.
